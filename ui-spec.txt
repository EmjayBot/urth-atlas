URTH ATLAS - CURRENT UI SPEC (continuation doc)
===============================================
Describes the UI as built. Future work continues from here — do not
regress the items below. Stack: Vite + React 18 + Leaflet + Tailwind,
deployed to GitHub Pages on push to main (base /urth-atlas/).

------------------------------------------------------------
1. DESIGN TOKENS
------------------------------------------------------------
- Colors: Primary #0e7490 (teal-blue), Hover #0c5a70, Light #e6f4f1,
  Border #d1d5db / #e5e7eb, Text #111827 primary / #6b7280 secondary,
  Map bg #e5e3df. Radius 6px. Shadows subtle.
- Fonts: header wordmark Bell MT Bold 22px teal (class .urth-logo —
  NEVER restyle: it is the brand). Sidebar section titles MS Reference
  Sans Serif; sidebar body Franklin Gothic Bold (scoped to `aside` only).
  Mono readouts JetBrains Mono. Nation map markers Bell MT Bold 13px;
  territory markers Bell MT Bold Italic 12px slate-gray #475569.

------------------------------------------------------------
2. LAYOUT
------------------------------------------------------------
[Header - 56px] Menu toggle + globe + "Urth Atlas" wordmark | centered
search ("Search Urth Atlas") | locate + measure buttons.
[Claim notice] Lives in the Markers section (amber box, like the measurement
disclaimer): claims must be approved, don't use this map for claims, link
to the current political export (https://urthmaps.com/maps/export/urth.png).
[Sidebar - 340px] Sections: Map Info (title "Urth Atlas", subtitle
"TEP Urth · urthmaps.com", live layer/image/projection/zoom/center/
markers/scale dashboard) | Base Layer (radio + opacity, dead zone 100-50
solid, fades 50-0 revealing the TEPmap underlay on desktop) | Thematic
Layers (stackable data overlays + overlay opacity) | Overlays (scale bar,
grid, pixel grid, coordinates, cities, subnational, nation markers) |
Measurements (tool picker, units, cursor readout, results) | Markers
(claim notice, add form, lists, submit).
[Map] Fills remaining space. Bottom-right zoom/recenter, bottom-left
layer pill (desktop), mobile tool/units bars on small screens.
[Footer] Scale strip: 1px = 2.518km, 1px2 = 6.34km2, spherical figures
marked hypothetical. [StatusBar] cursor readout + credits.

------------------------------------------------------------
3. MAP + SCALE CANON
------------------------------------------------------------
- Full-res world 11232x7525 px, Leaflet CRS.Simple, 5 world copies
  desktop / 3 on low-memory devices, infinite horizontal wrap, clamped
  vertical. Lat 75N-75S linear in y, lng 360deg across W.
- Urth is FLAT by canon (hence the cylinder easter egg). Ground truth is
  uniform Euclidean: 1px = 2.518km (exactly sqrt(50)/2.808), 1px2 =
  6.34126km2 (exactly 50/2.808^2, from a 4000x2680 @50km2/px export
  upscaled 2.808x). Spherical cos(phi) figures are a labeled hypothetical
  ("If Urth were a sphere"), never the primary readout.
- Graticule is true vectors (20deg meridians, 15deg parallels); pixel
  grid + coordinate labels are overlays. TEPmap SVG underlay easter egg
  at 0% base opacity (desktop only).

------------------------------------------------------------
4. MOBILE TIER (IS_LOW_MEM)
------------------------------------------------------------
- Serves downscaled variants stretched over FULL-res coordinates, so
  pins/wrap/measurements match desktop: blank-political-mobile (4096px),
  timezones-mobile + cities-mobile + subnational-mobile (3072px). Regenerate with
  `npm run images:mobile` (sharp, PNG masters as sources). Mobile URLs
  carry ?v=2 cache-busting — bump on regeneration.
- Disabled/hidden on phones: satellite, remote full-res overlays
  (topo/climate/currents/hydro/blank), TEPmap underlay, idle pre-warming.
  Cities + subnational default OFF on phones (each stretched overlay forces an extra resample pass that softens the base).
  Desktop behavior is unaffected by all of the above.

------------------------------------------------------------
5. MEASUREMENTS (finalize/lock model)
------------------------------------------------------------
- Tools: Measure (auto-completes on 2nd click), Path, Area. Units
  metric/imperial/both. Rubber-band hover preview; finalized shapes lock
  (clicks ignored, preview freezes solid).
- Finish via Finish button, double-click (pops the duplicate vertex
  Leaflet fires), or Enter. Clicking the active tool toggles it off.
  Esc removes the last point (exits when empty/finished). Undo/Clear
  resume the draft. Copy result / share link / save measurement.
- Disclaimer: "Verified — approximately accurate" — fine for reference;
  official wiki use must confirm with the official tool
  (https://urthmaps.com/docs#area).

------------------------------------------------------------
6. MARKERS (community places)
------------------------------------------------------------
- Registry public/positions.json: { kind: nation|capital|city|town,
  href, x, y } in full-res pixels, optional `territory` flag string on
  nations (renders the subnational marker style). Merged from shared +
  local (localStorage) minus removal marks.
- Add & place flow: form (name, kind buttons, optional wiki page,
  Territory checkbox for nations) saves the marker, then click the map to
  position it; Esc cancels. Submit opens a GitHub issue (needs a GitHub
  account) — auto-merged by map-update.yml, which preserves `territory`
  and carries it over when patches omit it.
- Nation markers are Bell MT text labels with halo (clickable, wiki-enriched
  popups with flag + summary, Copy/Remove actions). Settlement markers are
  tiered dots (capital/city/town) + nearest-neighbour flat-km readout.
  Territory popups badge "Territory".

------------------------------------------------------------
7. MAINTAINER MAP UPDATES (hidden mode)
------------------------------------------------------------
- Unlock per session by visiting ?maintainer=1 once; the flag lives in
  sessionStorage (the share-link writer rebuilds the query string, so it
  is intentionally NOT a persistent URL param). Unlocking reveals the
  "Map Updates" sidebar section (last).
- Upload slots are local files only: Political base, Satellite base,
  Time Zones, Cities, Subnational overlays. Remote CDN overlays update
  themselves upstream and are not listed. Satellite has no mobile
  variant (desktop-only layer).
- Validation: file must decode to exactly 11232x7525 (timezones raw
  11860-wide exports are rejected — crop first). Slot formats only
  (webp for map/satellite/timezones, png for cities/subnational).
- Mobile variants auto-generate in-browser via canvas
  (4096px base / 3072px overlays, webp) and commit alongside.
- Auth: maintainer pastes a GitHub PAT (fine-grained: Contents
  read+write, Pull requests read+write, this repo only; or classic
  `repo` scope). Token lives in tab memory only, sent solely to
  api.github.com. Repo coordinates in src/lib/github.js
  (REPO_OWNER/REPO_NAME) — update on turnover.
- Submit creates branch map-update/<slot>-<date>, commits both files,
  and opens a PR: nothing goes live until merged. Merging deploys via
  the normal Pages workflow.

------------------------------------------------------------
8. WHAT NOT TO DO
------------------------------------------------------------
- Never restyle the header wordmark (.urth-logo, Bell MT Bold).
- Never present spherical-corrected figures as ground truth.
- Never serve full-res (>~12MP) decodes to low-memory devices; never add
  a base/overlay layer without a mobile variant or an explicit mobile
  exclusion. Bump mobile ?v= counters when regenerating images.
- Never strip unknown fields (e.g. `territory`) in the map-update
  workflow or submit diff — carry them over in canonical key order.
- No third-party map branding anywhere; own UI only: Urth Atlas.

------------------------------------------------------------
9. TILED BASE + OVERLAYS (default on; ?tiles=0 opts out)
------------------------------------------------------------
- The political base, cities, and subnational overlays serve as z/x/y tile
  pyramids (public/tiles/<layer>/{z}/{x}/{y}.jpg|.png), levels -2..0 with
  level 0 = native 1:1. Closer zooms overzoom level 0 (same as the old
  stretched overlay); far zooms use pre-scaled overviews. Tiles wrap
  horizontally (custom CRS with wrapLng [0, 11232]), clamp vertically.
- Tile rows are BOTTOM-anchored (TMS, y=0 at bottom): 7525 % 256 != 0, so
  top-down files sit 101px off Leaflet's grid (hard seams). Columns stay
  left-anchored. CRS.Simple addresses rows as negative y — see tileUrlFor.
- Tiles are build artifacts (gitignored): fresh clones MUST run
  `npm run tiles:all` (needs sharp) or the base renders empty. CI builds
  them in deploy.yml before `vite build`. Container backdrop is flat
  ocean #7499b4 (no ghost preview) in tiles mode.
- Header brand mark: Phosphor globe-hemisphere-east duotone in accent
  teal #0e7490 (@phosphor-icons/react); the wordmark itself (.urth-logo)
  stays Bell MT.
