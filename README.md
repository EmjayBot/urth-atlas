# Urth Atlas

An interactive map of Urth, the world of The East Pacific.

Browse the political map and satellite imagery, measure distances, paths,
and areas in true flat-world kilometers, and explore community-submitted
places linked to the wiki. Works on desktop and phones, online and (once
visited) offline.

Live at **https://atlas.urthmaps.com**.

Map artwork is produced from the official GIMP sources by
[urth-imagery](https://github.com/urth-rp/urth-imagery) and refreshed
automatically whenever the source maps change.
